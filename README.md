# C4P数理モデル

書籍『クリエイト・フォー・パーソナリティ』（有村崚）で提唱した C4Q / C4P の概念に数理的な定式化を与えるモデルです。
書籍収録版（ver3）を全面改訂したものをマスター版として管理しています。

- **C4Q（Create-for-Quality）** — クオリティのための創作。状態量（社会的クオリティ $Y(a)$、実現誤差 $\|\epsilon\|$、実行可能領域 $\mathcal{F}_i$ の広さ）を改善するゲーム
- **C4P（Create-for-Personality）** — パーソナリティのための創作。経路量（意図の履歴、選択カーネル $\sigma_i$、写像の変容の軌跡、停止パターン）の蓄積

モデルの目的は数値化や予測ではなく、創作に対する態度の正確な記述です。

## ファイル構成

マスター版は書籍収録版（ver3）の全文を含み、各節冒頭の【書籍版との差分】注記で変更の有無と内容を明示しています。今後の改訂はマスター版に対して行います。

```
.
├── c4p_model.tex    # マスター版（これを編集する）
├── c4p_model.pdf    # ビルド済みPDF
└── archive/         # 過去バージョンのPDF
    ├── C4P_model_ver1.pdf
    ├── C4P_model_ver2.pdf
    ├── C4P_model_ver3.pdf        # ver3ドラフト
    └── C4P_model_ver3_book.pdf   # 書籍収録版（本改訂のスタート地点）
```

## ビルド方法

LuaLaTeX（TeX Live）でコンパイルします。フォントの同梱は不要です（jlreq のデフォルトフォントを使用）。

```bash
lualatex c4p_model.tex
lualatex c4p_model.tex   # 相互参照の解決のため2回
```

## 改訂履歴

| 版 | 内容 |
|---|---|
| ver1 | 初版 |
| ver2 | 三層射影モデルの整理 |
| ver3 | 候補集合モデルの導入。書籍『クリエイト・フォー・パーソナリティ』収録版（`archive/C4P_model_ver3_book.pdf` が収録版そのもの） |
| マスター版（ver4相当） | 書籍版全文を収録した上で、意図の二層化（δ^V / δ^S）、状態量／経路量によるC4Q/C4Pの再定義、選択カーネル σ_i の昇格、完成（停止時刻 τ）・凡庸さ（到達可能集合 R_i）・観測の交換（r_{j→i}）・運の所在の定式化を追加。Q&Aは36問（書籍版30問＋追加6問） |

書籍収録版からの変更点の一覧は `c4p_model.tex` 冒頭の「書籍収録版（ver3）からの変更点」、各所の変更は本文中の【書籍版との差分】注記を参照してください。
